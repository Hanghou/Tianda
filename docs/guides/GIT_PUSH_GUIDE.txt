## 推送方法

### 方法 1：使用 Gitee 个人访问令牌（推荐）

1. 登录 Gitee：https://gitee.com
2. 点击右上角头像 → 设置 → 私人令牌
3. 点击"生成新令牌"
4. 填写令牌描述（如：Integration项目）
5. 选择权限：勾选 "projects"
6. 点击"提交"，复制生成的令牌（只显示一次！）

7. 在 PowerShell 中运行：
```powershell
$env:Path = "D:\PortableGit\bin;" + $env:Path
git push -u origin master
```

8. 当提示输入用户名和密码时：
   - 用户名：huangdera
   - 密码：粘贴刚才复制的令牌

### 方法 2：修改远程仓库 URL（包含用户名）

在 PowerShell 中运行：
```powershell
$env:Path = "D:\PortableGit\bin;" + $env:Path
git remote set-url origin https://huangdera@gitee.com/huangdera/Integration.git
git push -u origin master
```

然后输入密码（或访问令牌）

### 方法 3：使用 SSH 密钥（最安全，一次配置永久使用）

1. 生成 SSH 密钥：
```powershell
$env:Path = "D:\PortableGit\bin;" + $env:Path
ssh-keygen -t rsa -C "13422523+huangdera@user.noreply.gitee.com"
```
按 Enter 使用默认路径，可以设置密码或直接 Enter 跳过

2. 查看公钥：
```powershell
Get-Content $env:USERPROFILE\.ssh\id_rsa.pub
```

3. 复制公钥内容，添加到 Gitee：
   - 登录 Gitee → 设置 → SSH 公钥
   - 粘贴公钥，点击"确定"

4. 修改远程仓库为 SSH 地址：
```powershell
$env:Path = "D:\PortableGit\bin;" + $env:Path
git remote set-url origin git@gitee.com:huangdera/Integration.git
git push -u origin master
```

## 后续使用

每次修改代码后，使用以下命令提交和推送：

```powershell
# 设置 Git 路径
$env:Path = "D:\PortableGit\bin;" + $env:Path

# 查看修改的文件
git status

# 添加所有修改
git add .

# 提交修改
git commit -m "描述你的修改内容"

# 推送到远程
git push
```

## 常用命令

```powershell
# 查看状态
git status

# 查看提交历史
git log --oneline

# 查看远程仓库
git remote -v

# 拉取最新代码
git pull

# 创建新分支
git checkout -b 分支名

# 切换分支
git checkout 分支名
```

## 提示

- 推荐使用方法 1（个人访问令牌），最简单
- 如果经常使用 Git，推荐配置 SSH 密钥（方法 3）
- 每次打开新的 PowerShell 窗口都需要先设置 Git 路径：
  $env:Path = "D:\PortableGit\bin;" + $env:Path

## 创建永久环境变量（可选）

如果不想每次都设置路径，可以添加到系统环境变量：

1. 右键"此电脑" → 属性 → 高级系统设置
2. 点击"环境变量"
3. 在"系统变量"中找到 Path，点击"编辑"
4. 点击"新建"，添加：D:\PortableGit\bin
5. 点击"确定"保存
6. 重启 PowerShell

之后就可以直接使用 git 命令，无需每次设置路径。
