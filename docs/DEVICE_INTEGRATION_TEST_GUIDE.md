# 设备集成测试指南

## 概述

本指南涵盖延迟线、激光器、光谱仪三个核心设备的集成测试，包括单独测试和预设执行测试。

---

## 一、设备连接测试

### 1.1 延迟线连接测试
```
步骤：
1. 连接延迟线到 COM 口
2. 在 UI 中选择正确的串口
3. 点击"连接"按钮
4. 观察状态指示器变为绿色

预期结果：
✓ 连接成功提示
✓ 状态指示器显示绿色
✓ 当前延迟值显示正常
```

### 1.2 激光器连接测试
```
步骤：
1. 连接三个激光器（种子源、FOPO、Stokes）
2. 在 UI 中选择对应串口
3. 点击各自的"连接"按钮
4. 观察状态指示器

预期结果：
✓ 三个激光器均连接成功
✓ 状态指示器全部显示绿色
✓ 当前参数显示正常
```

### 1.3 光谱仪连接测试
```
步骤：
1. 连接光谱仪到 USB 口
2. 点击"连接"按钮
3. 观察设备信息自动填充

预期结果：
✓ 连接成功提示
✓ 像素数、序列号、型号自动显示
✓ 积分时间范围显示正常
```

## 二、单设备功能测试

### 2.1 延迟线功能测试

#### 测试1：设置延迟值
```
步骤：
1. 确保延迟线已连接
2. 在输入框输入延迟值（如 1000.0 ps）
3. 点击"设置延迟"按钮
4. 观察当前延迟值更新

预期结果：
✓ 延迟值设置成功
✓ 当前延迟值显示为设置值
✓ 状态栏显示"延迟设置成功"
```

#### 测试2：归零功能
```
步骤：
1. 点击"归零"按钮
2. 等待归零完成

预期结果：
✓ 延迟值归零
✓ 当前延迟值显示为 0.0 ps
```

### 2.2 激光器功能测试

✓ 调试输出显示正确的命令帧

预期结果：
✓ 电流设置成功

#### 测试3：设置温度

预期结果：
✓ 温度设置成功

## 五、性能指标

### 5.1 延迟线
- 延迟精度：1 ps
- 延迟范围：0-10000 ps
- 响应时间：< 100 ms

### 5.2 激光器
- 电流设置精度：0.1 mA / 0.01 A
- 温度设置精度：0.1 ℃
- 响应时间：< 50 ms

### 5.3 光谱仪
- 单次测量时间：积分时间 + 50-100 ms
- 持续测量频率：
  - 积分时间 10 ms：约 9 Hz
  - 积分时间 50 ms：约 6.7 Hz
  - 积分时间 100 ms：约 5 Hz
- 像素数：2048 或 3648

### 5.4 预设执行
- 时间间隔精度：± 10 ms
- 最大预设行数：无限制（建议 < 100）
- 设备断开检测延迟：< 时间间隔

## 六、常见问题

### Q1: 预设执行时设备断开，如何恢复？
```
解决方案：
1. 重新连接设备
2. 检查设备状态
3. 重新开始预设执行
```

### Q2: 光谱仪持续测量时出现超时
```
原因：积分时间过长或数据传输慢
解决方案：
1. 减小积分时间
2. 增加采集间隔（修改代码中的 +100 ms）
```

### Q3: 激光器命令发送失败
```
检查项：
1. 串口连接是否正常
2. 波特率是否正确（9600）
3. 校验码是否正确
4. 查看调试输出
```

### Q4: 预设执行顺序不正确
```
检查项：
1. 确认预设表格行序号正确
2. 使用"上移"/"下移"按钮调整顺序
3. 查看调试输出确认执行顺序
```
