## 二、命令对照表（按设备分组）

> **表头约定**：`执行` = 用户操作的UI按钮 / `命令` = 实际发送字节序列 / `设备` = 接收命令的硬件 / `回复` = 设备返回字节 / `显示` = 项目处理后UI呈现

### 2.1 OHLD 激光泵（4 路独立串口，9600/8N1）

**协议格式**（详见 `LaserDriver/ohld_protocol.h`）：

```
帧格式：68 + 设备ID(4字节固定00) + 控制字(1B) + 数据长度(2B大端) + 数据域(N) + 校验码(1B) + 16
校验码 = 设备ID~数据域累加取低8位按位取反
```

**控制字定义**：
- `0x01` = 查询状态/电流/温度（`OHLD_CMD_QUERY`）
- `0x02` = 设置驱动电流（`OHLD_CMD_SET_CUR`，电流值×10，4字节大端）
- `0x05` = 开启激光器（`OHLD_CMD_OPEN`）
- `0x06` = 关闭激光器（`OHLD_CMD_CLOSE`）

| 执行（按钮） | 命令字节序列 | 设备 | 回复内容 | 显示 |
|---|---|---|---|---|
| **连接页：连接 Pump1~4**（`btnConnectPump1~4`）<br>调用 `connectOhldPump()`（连接OHLD泵串口） | 仅打开串口，无协议命令 | OHLD-1~4 泵 | — | `labelPump1~4ConnStatus` 状态指示灯变绿色，状态栏显示"种子源泵连接成功"等 |
| **连接页：断开 Pump1~4**（`btnDisconnectPump1~4`）<br>调用 `disconnectOhldPump()`（断开OHLD泵串口） | 仅关闭串口 | OHLD-1~4 泵 | — | 状态指示灯变灰，状态栏显示"已断开" |
| **振镜页：种子源泵确定**（`btnConfirmGalvoPump1`）<br>调用 `setOhldPumpCurrent(0, ...)`（设置pumpIndex=0电流-带弹窗查询） | ① `68 00 00 00 00 05 00 00 FB 16`（开启 0x05）<br>② `68 00 00 00 00 02 00 04 [VAL×10 大端4B] [CHK] 16`（设置电流 0x02）<br>③ `68 00 00 00 00 01 00 00 FF 16`（查询 0x01） | OHLD-1（pumpIndex=0） | 0x01 响应：`68 ID(4B) 01 LEN(2B) [启停1B 驱电2B 最大2B 温度2B 背光2B] CHK 16`（共 19+ 字节） | 弹窗"电流设置成功" + 状态栏 + **位移台页 `lineEditPump1Temp/Drive/Max/Back`** 同步刷新 |
| **振镜页：FOPO泵确定**（`btnConfirmGalvoPump2`）<br>调用 `setOhldPumpCurrent(1, ...)` | 同上，pumpIndex=1 | OHLD-2 | 同上 | 同上（位移台页 Pump2 显示框） |
| **振镜页：Stokes泵确定**（`btnConfirmGalvoPump4`）<br>调用 `setOhldPumpCurrent(3, ...)` | 同上，pumpIndex=3 | OHLD-4 | 同上 | 同上（位移台页 Pump4 显示框） |
| **位移台页：4泵确定**（`btnConfirmStagePump1~4`）<br>调用 `setOhldPumpCurrent(0/1/2/3, ...)` | 同上，pumpIndex=0/1/2/3 | OHLD-1~4 | 同上 | 同上（位移台页对应 4 个状态显示框） |
| **预设执行链路（静默版）**<br>调用 `setOhldPumpCurrentSilent()`（静默设置电流-不弹窗不查询） | 仅 ①+②，**不发送 ③ 查询** | OHLD-1~4 | 无回复处理 | 仅写日志，不刷新显示框 |

**示例 — 设置 Pump1 电流为 100mA**：
- 数据域：`100 × 10 = 1000 = 0x000003E8` → 字节 `00 00 03 E8`
- 校验码：`02+00+04+00+00+03+E8 = 0xED → ~0xED = 0x12`
- 完整发送：`68 00 00 00 00 02 00 04 00 00 03 E8 12 16`（共 14 字节）

**响应解析**（见 `ohldParseQueryResponse()`（解析OHLD查询响应帧），`ohld_protocol.h` 第 107~127 行）：
- 启停：1 字节，`0=关 / 1=开`
- 驱动电流 / 最大电流 / 温度 / 背光：均 2 字节大端，单位 `0.1mA / 0.1mA / 0.1℃ / 0.1mA`

### 2.2 延迟线 DelayLine（2 路独立串口，9600/8N1）

**协议格式**（详见 `DelayLine/delay_protocol.h`）：

```
7字节定长帧：FC + ID(1B) + FUNC(1B) + P1 P2 P3(3B) + FE
延迟线1 ID = 0x01，延迟线2 ID = 0x02
```

**功能码定义**：
- `0x04` = 设置时间延迟（`DELAY_CMD_SET_DELAY`，PS×1000→3字节大端）
- `0x07` = 归零（`DELAY_CMD_HOME`）
- `0x0B` = 停止运动（`DELAY_CMD_STOP`）
- `0x0E` = 查询当前位置（`DELAY_CMD_QUERY_POS`）

| 执行（按钮） | 命令字节序列 | 设备 | 回复内容 | 显示 |
|---|---|---|---|---|
| **连接 Delay1**（`btnConnectDelay`） | 仅打开串口 | 延迟线1 | — | `labelDelayStatus` 变绿，状态栏"延时线连接成功" |
| **连接 Delay2**（`btnConnectDelay2`） | 仅打开串口 | 延迟线2 | — | `labelDelay2Status` 变绿 |
| **断开 Delay1/2**（`btnDisconnectDelay/Delay2`） | 仅关闭串口 | — | — | 状态指示灯变灰 |
| **振镜页：延时确定**（`btnConfirmTimeDelay`）<br>调用 `setDelayTime()`（振镜页延迟线1设置入口） → `setDelayLineValue()`（统一控制方法） | ① `FC 01 07 00 00 00 FE`（归零 0x07）<br>② `FC 01 04 [PS×1000 大端3B] FE`（设置 0x04）<br>③ `FC 01 0E 00 00 00 FE`（查询 0x0E） | 延迟线1（`m_delayLine`） | 查询响应：`AA ... 当前位置3B ...` | 状态栏"延迟线1 延迟设置成功: X PS"+ `onDelayChanged()`（延迟值改变信号回调）信号回调 |
| **位移台页：延迟线1确定**（`btnConfirmStageDelayLine1`）<br>调用 `setDelayLineValue(m_delayLine, ...)` | 同上 | 延迟线1 | 同上 | 同上 |
| **位移台页：延迟线2确定**（`btnConfirmStageDelayLine2`）<br>调用 `setDelayLineValue(m_delayLine2, ...)` | ID 改为 0x02：`FC 02 07/04/0E ...` | 延迟线2（`m_delayLine2`） | 同上结构 | 状态栏"延迟线2 延迟设置成功"+ `onDelay2Changed()`（延迟线2值改变回调）信号 |

**示例 — 设置延迟线1 为 100PS**：
- 数据：`100 × 1000 = 100000 = 0x0186A0` → 字节 `01 86 A0`
- 完整发送（设置帧）：`FC 01 04 01 86 A0 FE`（共 7 字节）

**字节构造函数**：`delayToBytes()`（延迟值PS转3字节大端） in `delay_protocol.h` 第 60~70 行

### 2.3 位移台 ELLx（双台，单串口聚合，地址 `0`=台1 / `1`=台2）

**协议格式**（详见 `StageController/stage_protocol.h`）：

```
ASCII 文本帧：<地址><命令>[参数]\r\n
地址：'0' = 位移台1，'1' = 位移台2
```

**命令字符串定义**：
- `in` = 读取换算参数（`STAGE_CMD_GET_INFO`，返回 IN 帧含 pulsePerUnit）
- `sv<hex8>` = 设置最大速度（`STAGE_CMD_SET_SPEED`，32位有符号大端十六进制）
- `ma<hex8>` = 绝对位移（`STAGE_CMD_MOVE_ABS`，32位有符号大端十六进制脉冲数）
- `gs` = 查询状态（`STAGE_CMD_GET_STATUS`，返回 GS 帧）
- `gp` = 查询当前位置（`STAGE_CMD_GET_POS`，返回 PO 帧）
- `st` = 停止（`STAGE_CMD_STOP`）
- `ho<dir>` = 回零（`STAGE_CMD_HOME`，dir: 0=顺时针，1=逆时针）

| 执行（按钮） | 命令文本（ASCII） | 设备 | 回复内容 | 显示 |
|---|---|---|---|---|
| **连接 Stage1**（`btnConnectStage1`）<br>调用 `m_stageController->openPort1()`（位移台1打开串口） | 打开串口后，`readDeviceInfoDual()`（双台读换算参数）发送 `0in\r\n` | 位移台1 | `IN<地址><设备类型>...<pulsePerUnit>\r\n` | `labelStage1Status` 变绿；`pulsePerUnit` 缓存到 `m_deviceInfo1` |
| **连接 Stage2**（`btnConnectStage2`）<br>调用 `m_stageController->openPort2()`（位移台2打开串口） | 同上，地址=1：`1in\r\n` | 位移台2 | 同上结构 | `labelStage2Status` 变绿 |
| **断开 Stage1/2**（`btnDisconnectStage1/Stage2`）<br>调用 `closePort1()/closePort2()`（关闭对应位移台串口） | 仅关闭串口 | — | — | 状态灯变灰 |
| **位移台页：双台同步绝对位移**（`btnStageMoveAbsolute`）<br>调用 `on_btnStageMoveAbsolute_clicked()`（双台同步绝对位移槽函数） | **标准三步流程**：<br>① `0in\r\n` + `1in\r\n` → `readDeviceInfoDual()`（读换算参数）<br>② `0sv<8位hex>\r\n` + `1sv<8位hex>\r\n` → `setMaxSpeedDual()`（设速度）<br>③ `0ma<8位hex>\r\n` + `1ma<8位hex>\r\n` → `moveAbsoluteDual()`（双台同步绝对位移） | 位移台1+2 | 每条命令返回 `GS<地址><状态码>\r\n` 或 `PO<地址><位置hex>\r\n` | `onStage1PositionChanged()`（位移台1位置变化回调）/ `onStage2PositionChanged()`（位移台2位置变化回调）信号→`onStageMoveCompletedDual()`（双台移动完成回调）→ 状态栏"双台绝对位移: X mm，速度: Y pulse/s" |

**示例 — 双台移动到 +5mm（pulsePerUnit=2048）**：
- 脉冲数 = `5 × 2048 = 10240 = 0x00002800`
- 台1命令：`0ma00002800\r\n`（13 字节 ASCII）
- 台2命令：`1ma00002800\r\n`

**字节构造函数**：
- `ellxBuildFrame()`（构建ELLx ASCII指令帧含CRLF）
- `ellxPulsesToHex()`（脉冲数转8字符大端十六进制字符串）
- `ellxMmToPulses()`（位移mm按换算参数转脉冲数）

均位于 `stage_protocol.h` 第 76~98 行。

### 2.4 振镜控制卡（TCP/UDP 网络协议，非串口）

**通信端口**：

| 端口 | 协议 | 用途 |
|---|---|---|
| `5998` | UDP | 心跳监听 |
| `6002` | TCP | 图形参数下发 |
| `6003` | TCP | 控制指令下发 |

**协议格式**（详见 `GalvoMirror/galvo_protocol_v2.h`）：

```cpp
#pragma pack(push, 1)   // 全部结构体 1 字节对齐
struct GalvoControlAction {  // 控制指令 - 20 字节
    uint32_t nDebugType;     // 固定 114 ('r')
    uint32_t nOperation;     // 操作码 'e'/'r'/'p'/'c'
    uint32_t uParam;         // 保留 0
    uint32_t uStatus;        // 保留 0
    uint32_t uReserved;      // 保留 0
};
struct GalvoCommFrame {      // 图形参数（约 2KB+，含帧头 0x5A5AA5A5）
    int32_t          nHeader;       // 0x5A5AA5A5
    GalvoLaserPara   LaserPara;     // 激光参数
    GalvoMarkSetting stmark;        // 振镜运动参数
    GalvoShapeInfo   ShpaeInfo;     // 图形信息（点/线/圆）
    GalvoIOControl   IOControl;     // IO 控制
    GalvoPointPara   PointPara;     // 多点阵列（最大128点）
};
```

**操作码定义**（`GalvoControlMode` 枚举）：
- `'e'` (101) = 开始打标（`GALVO_CMD_START`）
- `'r'` (114) = 停止/复位（`GALVO_CMD_STOP`）
- `'p'` (112) = 暂停（`GALVO_CMD_PAUSE`）
- `'c'` (99)  = 继续（`GALVO_CMD_CONTINUE`）

**图形类型定义**（`GalvoShapeType` 枚举）：
- `0x01` = 点（`GALVO_SHAPE_POINT`）
- `0x02` = 线（`GALVO_SHAPE_LINE`）
- `0x03` = 圆（`GALVO_SHAPE_CIRCLE`）
- `0x08` = 多点阵列（`GALVO_SHAPE_ARRAY`）

| 执行（按钮） | 命令（结构体）→ 字节流 | 设备 | 回复内容 | 显示 |
|---|---|---|---|---|
| **连接振镜**（`btnConnectGalvo`）<br>调用 `m_galvoMirror->connect()`（建立振镜网络连接） | 建立 TCP/UDP socket，启动心跳监听 | 振镜控制卡 | UDP `5998` 周期心跳包 | `labelGalvoStatus` 变绿；`onGalvoHeartbeatChanged(true)`（心跳状态变化回调） |
| **断开振镜**（`btnDisconnectGalvo`）<br>调用 `m_galvoMirror->disconnect()`（关闭振镜网络连接） | 关闭 socket | — | — | 状态灯变灰 |
| **图形选择**（`rbGalvoShapePoint/Line/Circle/Array`）<br>调用 `on_rbGalvoShape*_toggled()`（图形类型切换槽） | 仅本地状态切换，**不发命令** | — | — | UI 启用/禁用对应输入框 |
| **下发参数**（`btnGalvoSetParam`）<br>调用 `on_btnGalvoSetParam_clicked()`（下发图形参数槽） | 经 **TCP:6002** 发送 `GalvoCommFrame` 结构（约 2KB+） | 振镜 | ACK | `textEditGalvoLog` 显示"图形参数下发成功" |
| **开始打标**（`btnGalvoStart`） | 经 **TCP:6003** 发送 `GalvoControlAction{nDebugType=114, nOperation='e'(101), 0, 0, 0}` 共 20 字节 | 振镜 | ACK | 日志"开始打标" |
| **停止/复位**（`btnGalvoStop`） | 同上结构，`nOperation='r'(114)` | 振镜 | ACK | 日志"停止/复位" |
| **暂停**（`btnGalvoPause`） | 同上，`nOperation='p'(112)` | 振镜 | ACK | 日志"暂停" |
| **继续**（`btnGalvoContinue`） | 同上，`nOperation='c'(99)` | 振镜 | ACK | 日志"继续" |
| **清空日志**（`btnGalvoClearLog`） | 仅 UI 操作，不发命令 | — | — | 清空 `textEditGalvoLog` |
| **预设执行链路（振镜跳转）**<br>调用 `m_galvoMirror->scannerJump(x, y, z)`（振镜跳转到坐标） | 经 **TCP:6003** 发送跳转指令 | 振镜 | ACK | 内部日志，无UI弹窗 |

**关键字节布局示例 — 开始打标（20 字节，小端序）**：

```
72 00 00 00     ← nDebugType = 114 = 0x72
65 00 00 00     ← nOperation = 'e' = 101 = 0x65
00 00 00 00     ← uParam
00 00 00 00     ← uStatus
00 00 00 00     ← uReserved
```

### 2.5 OPTOSKY 光谱仪（2 路独立串口，根据厂家 SDK 配置波特率）

**协议格式**（详见 `Spectrometer/spectrometer_protocol.h`）：

```
帧格式：AA 55 + Length(2B大端) + Cmd(1B) + Data(N) + Checksum(1B)
```

**主要命令ID定义**（`SpectrometerCmd` 命名空间，共 26 个命令，仅列项目用到的）：
- `0x14` = 设置积分时间（`SET_INTEGRATION_TIME`）
- `0x16` = 开启CCD扫描-异步（`START_SCAN_ASYNC`）
- `0x17` = 读取CCD采集数据（`GET_SPECTRUM_DATA`，配合 0x16 使用）
- `0x19` = CCD连续采集控制（`CCD_CONTINUOUS_SCAN`）
- `0x1E` = 开启CCD扫描-同步（`START_SCAN_SYNC`，软件触发）
- `0x41` = 获取当前积分时间（`GET_INTEGRATION_TIME`）
- `0x55` = 获取波长标定系数（`GET_WAVELENGTH_COEFF`）

| 执行（按钮） | 命令字节序列 | 设备 | 回复内容 | 显示 |
|---|---|---|---|---|
| **连接 FOPO/Stokes 光谱仪**（`btnConnectSpectrometerFOPO/Stokes`）<br>调用 `m_spectrometer*->connect()`（光谱仪连接） | 通过厂家 SDK `Driver.dll` 打开串口 | FOPO/Stokes 光谱仪 | — | `labelSpectrometer*Status` 变绿 |
| **断开** | SDK `Close()` | — | — | 状态灯变灰 |

## 四、备注与已知特殊点

1. **OHLD 设置电流流程**：UI 一次"确定"按钮触发 **3 条命令**（开启 0x05 → 设置 0x02 → 查询 0x01），不是单条。预设执行链路使用 `setOhldPumpCurrentSilent()`（静默设置电流-不弹窗不查询），省略最后一步查询以提高速度。

2. **延迟线设置流程**：每次"确定"也是 **3 条命令**（归零 0x07 → 设置 0x04 → 查询 0x0E）。`setDelayLineValue()`（统一双延迟线控制方法）内部 `home()`（归零）是阻塞的（带等待），单次耗时数秒。

3. **位移台双台同步**：`moveAbsoluteDual()`（双台同步绝对位移）实际是**串行发送台1+台2命令**，不是真正的硬件同步。两台运动开始时间有约 10~50ms 的偏差，运动过程中独立。

4. **振镜控制卡心跳**：连接后由 UDP 5998 端口持续接收心跳包，断开则触发 `onGalvoHeartbeatChanged(false)`（心跳状态变化回调），UI 自动反映离线状态。

5. **光谱仪积分时间**：当前代码默认积分时间从配置或 UI 输入读取，单次测量前必先发 `0x14 SET_INTEGRATION_TIME`。

6. **位移台扫描功能**（`btnStageScanStart` 等）：UI 控件已就位但 cpp 槽函数仅有 TODO 注释，未实现协议命令（待后续开发）。

7. **OHLD 泵下发单位 vs 表格列名**：位移台页"波长调谐"表第 4/5/6/7 列名标注"功率（mW）"，但实际下发到 OHLD 时按 mA 处理（直接当电流值）。这是历史遗留语义，**未来若要做 mW→mA 换算需在 `executePowerPresetStage()`（执行单个功率预设-位移台页）中追加单位转换**。

8. **振镜页 vs 位移台页设备共享**：

| 设备 | 振镜页 | 位移台页 | 共享方式 |
|---|---|---|---|
| FOPO 光谱仪 | ✅ 主图 | ✅ `_S` 镜像 | 同一 `m_spectrometerFOPO` 实例 |
| Stokes 光谱仪 | ✅ 主图 | ✅ `_S` 镜像 | 同一 `m_spectrometerStokes` 实例 |
| 延迟线1 | ✅ `btnConfirmTimeDelay` | ✅ `btnConfirmStageDelayLine1` | 同一 `m_delayLine` 实例 |
| OHLD 种子源/FOPO预放/Stokes（pumpIndex 0/1/3） | ✅ 三泵确定按钮 | ✅ 四泵确定按钮 | 同一 `m_ohldPumps[i]` 串口实例 |
| OHLD 主级泵（pumpIndex 2） | ❌（已删除） | ✅ `btnConfirmStagePump3` | 位移台页独占 |
| 延迟线2 | ❌ | ✅ `btnConfirmStageDelayLine2` + 波长调谐执行链路 | 位移台页独占 |
