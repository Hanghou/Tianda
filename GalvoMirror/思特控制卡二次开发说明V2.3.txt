第 1 章  概述 
1.1 GMC 卡功能概述 
GMC 板卡是由深圳市大族思特科技有限公司自主研发的振镜运动控制卡，目前该控制卡实现的主要功
能有： 
1、支持 2D、3D、飞行打标（定制）、四轴联动（定制）等功能； 
2、支持三种振镜数据通信协议，分别是 XY2-100，SPI 以及 SL2 通信协议； 
3、采用 TCP\IP 通讯协议，最多可同时连接并控制两百多张控制卡，只需改电脑 IP，无需其他配置； 
4、提供 C++、C#两种二次开发语言； 
5、支持光纤激光器（如 IPG、SPI、锐科、JPT 等）、CO2 激光器、紫外激光器、绿光激光器，提供
8 路数字能量控制信号与两路模拟量控制（0~10V）； 
6、自带高精度校正软件，校正一次，即可永久使用，无需二次开发人员频繁的加载校正文件。本控制
卡校正文件保存在控制卡里，断电重启也不会丢失，不需要其他软件再次加载校正文件。 
7、支持双校正表存储，可同时控制两个校正表不一样的方头工作； 
8、1 路编码轮读取信号，2 路伺服电机差分控制信号，15 路通用 IO 信号； 
9、支持单文档、多文档脱机打标。 
第2章 IP 设置 
因为本控制卡是通过以太网与电脑进行通讯的，因此在使用本控制卡之前，需要对电脑的 IP 进行设
置，IP 地址设置网段为 172.18.34.2~172.18.34.123 均可，子网掩码 255.255.255.0，不过要避免电脑的 IP
与卡的 IP 一致，控制卡初始 IP 地址为 172.18.34.227（此 IP 地址可以更改，不过网段不能改变），另外控
制卡在上电时会产生一个临时的 172.18.34.226 的地址，等卡上电初始化完成之后此 IP 就会消失，也避免
使用此初始化的 IP 地址。因此除了卡的 IP（172.18.34.227）与初始化 IP（172.18.34.226）之外，其他
IP 随意设置。 
 
4 
 
另外，本控制卡可以支持一个上位机软件同时控制多张控制卡打不同图形的功能，若要实现此功能，
需要将控制张卡默认的 172.18.34.227 地址改变一下，可以改为 172.18.34.228、
172.18.34.229~172.18.34.254 等。若多张卡的 IP 地址一样，上位机软件是无法区分不同的卡。在有多张
控制卡的情况下，需要使用交换机，在电脑上插入不同的网卡可能会出问题，完成以上 IP 设置后，就可以
使用自带的打标软件连接控制卡了。 
 
第3章 控制卡硬件介绍 
3.1 GMC2 与 GMC4 
目前控制卡常用的两个版本主要是 GMC2 与 GMC4，相比于 GMC2，GMC4 主要做了以下三点变更： 
①通用 IO 接口由之前 DB25 变更成 DB37； 
②差分信号采集由一路增加到两路，即 GMC2 只能实现单轴飞行打标功能，而 GMC4 可以实现双轴
打标控制，一般应用于四轴联动等系统； 
③Z 轴控制由 DB37 端口变更成 DB25 端口。 
④激光器报警脚位反馈，引脚按照一一对应的定义设计 
本说明书只针对 GMC4 的硬件部分进行介绍，GMC4 功能完全兼容 GMC2.

3.2.5    J11 激光器控制接口 
此端口采用 DB25 母头的端口，主要用于激光器控制。 
 
D0~D7：8 位数字量输出，主要用于激光器的能量控制，常见的 IPG、JPT、锐科等激光器均是通过
此八个引脚进行控制。我们可以理解为那 8 个引脚就是一个二进制数，二进制 11111111，十进制为 255，
也是 100%能量。二进制 01111111，十进制 127，也就是 50%左右能量。在程序中，可以通过结构体
MarkParameter 中的 LaserPower 变量来改变此值，输入 50 代表 50%能量输出，输入 100 代表 100%能
量输出。 
Pin9 HLATCH，能量锁存信号输出，此信号用来告诉激光器需要变更能量，当我们在软件中改变能
量时，此引脚会自动变化，一般此信号会配合 D0~D7 一起变化； 
Pin10  脉宽使能信号，此信号可忽略，为了客户接线方便可用 22 脚代替（激光器 22 脚一般是脉宽
使能脚位）； 
Pin11、Pin12、Pin16、Pin21，即 ALARM1、2、3、4 信号，此信号为输入信号，用于接受激光器
报警状态输入。在激光器中，这四个引脚可以组成 16 种激光器状态，可根据四个输入脚位来判断此刻激光
器状态。不同厂家以及不同型号的激光器的不同组合有不同含义，具体需要查看使用激光器的说明书。目
前通用控制卡只提供接受这四个输入状态，但没有做处理，用户可以调用 HM_GetLaserInput()函数来获取
状态信息，再根据此款激光器说明书来判断激光器报警与否，以下为截取的 IPG 激光器中 YLPN 19 rack 
mountable 系列中的一款状态信息作为参考，其他型号的状态反馈跟这个可能不同！

Pin20  频率输出脚位，其主要作用是输出 TTL 类型脉冲信号，在脉冲型激光器中，激光器收到一个
脉冲信号则会发射一个激光点，其频率越大，发射的激光点越多。CO2 或者紫外激光器，一般情况下只需

四个参数控制。其中 DutyCycle 代表在出激光打标时频率的占空比，Frequency 代表在出激光打标时的频
率(kHz)，StandbyFrequency 代表在打标完成后，或者跳转时的频率(kHz)，StandbyDutyCycle 代表在打
标完成后，或者跳转时的频率占空比。

打标速度：出激光部分速度，速度越大，用时越短，但效果可能会差； 
跳转速度：从这个图形跳转到另一个图形的速度，也是指不出激光的轨迹运动速度； 
激光能量：调节激光功率大小，能量越强打出图形痕迹越明显，取值范围 0~100； 
Q 频率：激光器出光的频率，频率越大，激光出来的点就越多，取值范围 0~10000； 
开激光延时：开始打标时激光延时多久后才出光，取值范围-320~＋∞； 
太大：振镜往后走得太多，激光才打开，笔画的开始会缺失。 
太小:  振镜还没有到位就出光，也就是提前出光了。 
关激光延时：在轨迹打标完了以后，延时多久关光，取值范围-320~＋∞； 
太大：振镜轨迹已经到位，并开始下一段轨迹时，激光还处于开启状态，会造成拖尾或者多打的现象。 
太小：振镜还未充分转到，激光就关闭，笔画的末尾会不够长。

打标延时（走笔延时）：打标结尾后振镜延时时间，取值范围 0~＋∞； 
太大：结尾形成重点。 
太小：结尾变形，图形无法闭合。

4.3 HM_HashuUDM.h 头文件函数库 
此指令库主要是生成打标数据，最后生成一个 UDM.BIN 文件。此文件包含打标参数、激光控制参数、
图形数据点坐标、输入输出信号等，所有的控制指令都包含在此文件中，最终通过前文的通讯库函数发送
给控制卡，控制卡即可控制振镜运动并出激光。 
此头文件中有函数后面带了一个_N 结尾，代表此函数可以进行异步调用，即在同时连接多张控制卡
时，需要同时生成不同的 UDM.BIN 打标文件，可以调用此函数，在调用此函数之前一定要先调用
UDM_SetUdmCount(int count)函数，即指定同时生成打标数据的个数。 
所有不带_N 结尾的函数，不可以进行多线程生成多个 UDM 文件，否则会造成读写混乱。 
说明：在打标过程中时，其实就是从头到尾按照顺序读取 UDM.BIN 文件中的内容，读取一行内容则执行
一行指令，因此调用这些指令函数的顺序就代表了打标时执行的先后顺序。

第 5 章 DEMO 软件使用指南 
在 DEMO 软件中，写了整个打标流程，包括寻找 IP、连接设备、设置打标参数、激光参数以及打标
图形等，用户可以在 DEMO 软件的基础上进行快速开发，前面文档可以作为指导性参考，主要的函数应用
在 DEMO 中均有体现，把 DEMO 的流程看懂，就基本可以进行自己项目的定制开发了。DEMO 提供了两
种开发语言 C++与 C#，以下分别讲解。因为软件与控制卡的通讯都是基于窗口句柄进行信号交互，因此
必须在 MFC 或者 Form 窗体上进行开发，否则无法进行数据交互，无法控制打标操作。另外，在可执行文
件目录下必须有以下三个文件，缺一不可：HM_Comm.dll、HM_HashuScan.dll、system.ini。 
 
39 
整个打标流程如下： 
1、连接设备； 
2、选择打标协议以及需要打标的图形； 
3、点击开始打标按钮； 
4、开始打标后，会给打标参数、激光参数赋值，根据选择的图形生成 UDM 文件； 
5、把 UDM 打标文件下载到控制卡中去； 
6、打标文件下载成功后进入下载完成消息函数中； 
7、在下载完成消息函数中调用开始打标函数 HM_StartMark(); 
8、控制卡开始打标，激光器同时出激光； 
9、打标完成，进入打标完成消息函数； 
10、整个打标过程结束。 
5.1 C++ MFC 版本  DEMO 
5.1.1 窗口初始化 
在窗体初始化函数 OnInitDialog()中，需要调用控制卡初始化函数，即 HM_InitBoard(this->m_hWnd);
调用此函数后即可建立通信关系。打开软件初始化时，控制卡开启与否均不影响，当控制卡已经上电且电
脑 IP 设置正确，那么程序会自动进入消息回调函数中，来通知软件控制卡已经找到，并且可以连接。 
5.1.2 消息回调函数 
在 BEGIN_MESSAGE_MAP(CST_MarkDemo_CPPDlg,  CDialogEx)消息函数中需要加入以下几个
消息函数，用于时时获取控制卡的状态信息，如下： 
//搜索IP 地址  Device status message map 
ON_MESSAGE(HM_MSG_DeviceStatusUpdate,OnMsgDeviceEhco) 
//打标过程中进度反馈 
ON_MESSAGE(HM_MSG_ExecProcess, ExecProcess) 
//下载完成download finish message map 
ON_MESSAGE(HM_MSG_StreamEnd,OnMsgUDMDownloadEnd) 
//打标完成      executed finished message map

5.1.6 IO 设置 
在与自动化配合时，往往需要进行 IO 操作，控制 IO 的方式采用了两种模式，一种时在线读取输入信
号与在线设置输出信号，另外一种是将 IO 信息写入 UDM.BIN 文件中去，在打标的过程中动态控制。 
①在线控制 IO 说明： 
HM_GetInput_GMC2()此函数为在线读取控制卡 IN0~IN14 的输入状态，需要将返回的值转成二进制，按
照从低位到高位的顺序，依次判断状态，0 代表不导通，1 代表导通。如十进制为 89，转成二进制为 1011001，
那么对应的输入状态为 IN14~IN7 不导通、  IN6 导通、IN5 不导通、IN4 导通、IN3 导通、IN2 不导通、IN1
不导通、IN0 导通。此时软件可以根据这些不同的输入状态进行不同的操作，比如选择不同的打标图形等。 
HM_SetOutputOn_GMC2 与 HM_SetOutputOff_GMC2 ， 调 用 此 函 数 则 代 表 在 线 控 制 指 定 脚 位
(OUT0~OUT15)的输出状态，ON 代表电平拉高 5V 输出，OFF 代表电平拉低 0V 输出。 
②UDM 中控制 IO 说明 
UDM_SetInput，在创建 UDM 文件时，在指定位置调用此函数，那么当打标在运行到这一步时，将会处于
等待状态，直到外部给了正确的输入信号才会往下执行，目前只支持 IN0~IN7。 
UDM_SetOutPutOn 与 UDM_SetOutPutOff 函数则代表，打标过程中，执行到此处时，将控制指定输出脚
位的拉高或者拉低。 
③代码举例说明： 
UDM_SetInput(0) 
UDM_AddPolyline2D(line,2,0); 
UDM_SetOutPutOn(0); 
UDM_SetInput(1) 
UDM_AddPolyline2D(circle,360,0); 
UDM_SetOutPutOff(0); 
UDM_SetOutPutOn(1); 
在上述代码时，一开始设置了 UDM_SetInput(0);代表此时需要外部触发 IN0，否则程序会一直卡这里，
一直等待输入信号。当外部 PLC 给了输入信号以后，开始打直线，当直线打完之后，会把 OUT0 引脚变成
高电平。此时继续往下执行，又需要 PLC 触发 IN1 信号，当控制卡收到来自 PLC 的 IN1 信号时，开始打
圆圈，打完圆圈以后，会将 OUT0  设置成低电平，然后又将 OUT1 变成高电平。

5.1.7  红光预览 
某些激光器有红光预览的功能，在点击红光预览时，调用 HM_SetGuidLaser(enable)函数，传入 true
时，J11 端口 P22 红光脚位立即变成高电平 5V 输出，如果此时直接进行打标，那么 J11 端口的 PIN19 则
持续保持低电平输出；若要恢复正常出光打标，则需要设置成 false。 
另外对于个别 MOPA 类型的激光器，他们的红光脚位与脉宽使能脚位都是 P22，这就造成不同的功
能共用一个脚位的情况，有时候会有冲突。比如在设置了红光预览 HM_SetGuidLaser(true)以后（P22 变
高电平），又开启了脉宽使能模式（参数结构体中 PulseWidthMode = 1），此时需要先拉高 P22，然后再拉
低 P22 才能实现改脉宽的功能，但拉低了 P22 又会使红光关闭。所以我们在应用层面做了一个限制，也就
是红光预览的时候不允许改变脉宽。也就是在使用了 MOPA 类型的激光器时，生成 UDM.BIN 文件时，需
要告知底层此处是红光预览，需要屏蔽改变脉宽的功能，再设置打标参数之前，调用
UDM_SetGuidLaser(true)函数即可，如下： 
 
 
 
UDM_SetProtocol(comboxProtocol.GetCurSel(),0); 
UDM_SetGuidLaser(true);//开启红光 
UDM_SetLayersPara(getMarkParameter(),2); 
当然也需要配合在线设置红光的函数 HM_SetGuidLaser()一起使用。

③532nm 激光器，一般称作绿光激光器；④10240nm 激光器，也叫 CO2 激光器；

6.1.1 光纤激光器 
目前市面上用的较多的是光纤激光器，常见品牌大致有 IPG、SPI、JPT、锐科、大族的 MP 激光器，
性能方面我们暂不提，只从能量控制方式上又可以分为两类； 
第一类是 IPG、JPT、锐科、大族 MP 激光器。这几个厂家的激光器，其能量是通过数字量控制，8
个引脚一起控制，即 8 个引脚全部高电平时代表 100%能量，全部低电平时 0%能量。我们可以理解为那 8
个引脚就是一个二进制数，二进制 11111111，十进制为 255，也是 100%能量。二进制 01111111，十进制
127，也就是 50%左右能量。0 代表低电平，1 代表高电平。也可以这么理解：设置 PIN1~8 的 TTL 信号，
通过 TTL 信号的组合来设置泵浦激光二极管的电流，即激光器的输出功率。通过 PIN1~8 可以设置 0~255
范围内的编码，对应于 0%~100%的功率输出（实际光学功率输出可能并非与这些设置成线性关系） 
其中大族 MP 激光器、JPT 激光器，是可以设置脉宽值（单位 ns，与 Q 脉宽是两个概念），在不同的
脉宽之下，同样的频率功率，打出来的能量会有差异，一般调节工艺时会需要用到，MarkParameter 参数
结构体中 PulseWidthMode = 1 时则启用改脉宽的功能，PulseWidth 则是代表具体脉宽值，单位是 ns，下

第二类是 SPI 类型的激光器，这一类激光器的特点就是其能量控制是由模拟量控制，0~10V 代表
0%~100%能量。（所有需要 0~10V 控制时，均可采用 SPI 激光器），可以通过 MarkParameter 结构体中的
AnalogMode=1 设置，当 AnalogMode= 1 时，此时结构体中的的能量设定值就代表模拟量的大小，这时候，
能量百分比会转成电压值，10%能量时输出 1V，50%能量时，输出 5V，100%能量时输出 10V，AnalogMode=

6.1.2  紫外、CO2、绿光激光器 
相对于光纤激光器，这三种类型的激光器控制上比较简单，一般情况下，只需要一个 Q 频率信号就能
控制其开关光，其能量大小由占空比决定（占空比=脉宽  /  周期）。遇到此类激光器时，需要把不出光 Q
频率与不出光 Q 脉宽设置成 0，否则激光器会一直出光，无法关闭。CO2 激光器会灼伤皮肤，请务必注意

6.1.3  关于激光频率说明 
像光纤激光器这种，要控制它出光，其所需信号多达十几个，所有信号均满足时才能出光，因此，其
不出光 Q 频率与不出光占空比可以不设置成 0，尽量让不出光 Q 频率等于出光 Q 频率、不出光占空比等于
出光占空比。 
注意：若强行把不出光占空比设置成 0，对于某些性能不好的激光器来说，其反应较慢，会造成起点频率
异常，激光点间距以及点能量异常，建议都设置成一样，可以避免此现象。另外占空比最好是 0.5，也就
是 Q 脉宽是 Q 周期的一半。 
像 CO2、紫外、绿光等激光器，它只需要一个 Q 频率与 Q 脉宽信号，因此必须把不出光 Q 频率与不
出光占空比设置成 0，否则激光无法关闭。当然，部分厂家激光器除了此信号外，可能也需要 laseron 信号，
这时候，是不是设置 0 就不影响了。 
 
6.3 关于 Q 频率、Q 脉宽、Q 周期概念 
Q 周期（T）与 Q 频率（F）是倒数关系，即 T=1/F。周期单位为秒（S），频率单位为赫兹（HZ）。
通常在激光器行业中，一般用 Q 频率做单位，不用 Q 周期，其中占空比  =  脉宽  /  周期，由此公式可知占
空比范围时 0~1 之间。 
如果是光纤激光器，建议占空比 dutyCycle 为 50%。 
如果是 CO2 这种类型的激光器，其能量是由占空比决定，因此建议把界面上的能量百分比赋值给占空比，
如用户输入 50%能量，则 dutyCycle=50%。

7.1 3D 打标基本原理 
若 要 启 用 3D 打 标 功 能 ， 需 要 将 UDM_SetProtocol(int  nProtocol,int  nDimensional) 函 数 中 的
nDimensional 值设置为 1，同时添加图形轨迹时需要调用 UDM_AddPolyline3D()函数。 
 
51 
常规打标中，只需要控制 XY 坐标，即可在物体表面打出想要的图形，其激光聚焦主要由镜头决定，
镜头固定时，则焦距固定。一般这种镜头打标范围较小，大多在 300mm 以内，无法满足更大范围需求，
且其工作面只能在二维空间，无法时时变焦，因此产生 3D 打标系统。3D 打标系统打标幅面比较大，因其

7.2  第三轴 Z 值与焦距关系 
在二次开发中，定义了一个点的结构体 structUdmPos，其中有 xyz 三个变量，x、y 即位置坐标点。
z 值即为控制 Z 轴的值，单位 mm。z=1 即为 z 轴运动 1mm。但是需要注意的是，z 轴运动 1mm 并不代表
实际光的焦距 f 变化 1mm。z 值与焦距 f 需要建立函数关系，即我们需要知道 z 值变化某个值时，相应的 f
的变化量。确定 z 与 f 关系的过程，一般叫做三维校正。以下为常见使用方式，仅仅提供思路参考。 
如下图所示，其中基本面焦距 H，指的是 3D 方头底部到打标的基准位置的高度，设备安装完成后，
此高度即固定，可以用尺子测量此高度。通常基本面（0,0）位置处，z=0。也就是设备安装好以后，在（0，
0）位置处，z 写入 0，是能聚焦的。

f1 = sqrt(X1 * X1 + Y1 * Y1 + H * H) 
f2 = sqrt(X2 * X2 + Y2 * Y2 + H * H) 
... 
fn = sqrt(Xn* Xn + Yn * Yn + H * H)

2.5D 系统指的是，在同一平面内的 Z 值全部相等，不同高度的平面时 Z 值不等。其光路系统是由 3D

内 Z 值一样，而 3D 系统同一平面内则 Z 值不一样。

第 8 章  脱机打标 
GMC 控制卡支持单文档脱机打标与多文档脱机打标功能，脱机完成后，则无需再打开电脑或者软件，
只用给 IN0 输入信号，控制卡即可自行打标，每触发一次打一次标。多文档脱机打标时，需要插入 SD 存
储卡，单文档脱机时则无需插入。在需要打标固定图形，且节省成本不想配备电脑时，脱机打标是一个很
好的选则。 
8.1 单文档脱机打标 
顾名思义，单文档脱机指控制卡只能执行一个打标文档，也就是只存储一个 udm.bin 打标文件，当外
部给 GMC 卡 IN0 触发信号以后，控制卡则立即执行打标动作。 
在使用脱机打标之前，需要先调用 HM_SetBurnMode 函数设置脱机模式，单文档模式传入值为 1 即
可，然后调用 HM_DownloadMarkFileSync()函数将 udm.bin 打标文件下载到控制卡中，等打标文件下载完
成后再调用 HM_BurnMarkFile(ipIndex,true)函数进行脱机文件固化即可，此时触发 IN0 以后，控制卡即可
打标，断电重启以后依旧生效。
