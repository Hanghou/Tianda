引脚定义 :
All data sent to/from the spectrometer is encoded in Hexadecimal format.
Head: used to locate the start of a communication packet, fixed to” 0xAA 0x55”.
Length: number of bytes from “Length” to “Checksum”.
Cmd: command ID
Data: The Data is determined according to the command, and the Data can be empty.
Checksum: Accumulation of all bytes from "length" to "data", the result takes the lower 8 bits
Checksum = (Length + Cmd ID + Data)&0xFF

byte is 0xE8.

Host send： AA 55 00 06 1E 00 01 25
