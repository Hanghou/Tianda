# 光谱仪功能测试指南

## 已完善的功能

### ✅ 1. 单次测量
**功能**：执行一次光谱采集，显示结果

**测试步骤**：
1. 连接光谱仪
2. 点击"单次测量"按钮
3. 等待采集完成（根据积分时间）
4. 查看图表显示的光谱数据

**预期结果**：
- 图表显示光谱曲线
- 状态栏显示"光谱采集成功"
- 调试输出显示像素数

### ✅ 2. 持续测量（实时测量）
**功能**：连续采集光谱数据，实时更新显示

**实现方式**：使用 QTimer 定时触发单次测量

**测试步骤**：
1. 连接光谱仪
2. 点击"持续测量"按钮
3. 观察图表实时更新
4. 点击"停止测量"按钮停止

**预期结果**：
- 图表持续更新光谱数据
- 状态栏显示"开始持续测量（间隔: XXX ms）"
- 点击停止后，测量停止

**采集间隔**：
- 默认间隔 = 积分时间 + 100ms
- 例如：积分时间 10ms，则间隔 110ms
- 采集频率 ≈ 9 Hz

### ✅ 3. 停止测量
**功能**：停止持续测量

**测试步骤**：
1. 在持续测量过程中
2. 点击"停止测量"按钮

**预期结果**：
- 定时器停止
- 状态栏显示"持续测量已停止"
- 图表停止更新

## 协议实现细节

### 单次测量（命令 0x1E）
```
发送: AA 55 00 06 1E [4字节积分时间] [校验] 
接收: AA 55 [长度] 1E [状态位] [光谱数据] [校验]
```

**数据解析**：
- 状态位：0x00 = 成功，0xFF = 失败
- 光谱数据：每个像素 2 字节（大端序）
- 像素数 = (数据长度 - 1) / 2

### 持续测量实现
**方案**：定时器 + 单次测量

```cpp
// 启动持续测量
m_measureTimer->start(intervalMs);  // 启动定时器
m_isContinuousMeasuring = true;

// 定时器触发
void Integration::onMeasureTimeout()
{
    if (m_isContinuousMeasuring) {
        m_spectrometer->startScan();  // 执行单次测量
    }
}

// 停止持续测量
m_measureTimer->stop();
m_isContinuousMeasuring = false;
```

**优点**：
- 实现简单，逻辑清晰
- 不依赖设备的连续模式
- 易于控制和调试

**缺点**：
- 采集间隔受限于积分时间和数据传输时间
- 最高频率约 10-20 Hz（取决于积分时间）

## 常见问题

### Q1: 持续测量时图表更新很慢
**原因**：积分时间设置过长

**解决方案**：
- 减小积分时间（如果光强足够）
- 采集间隔 = 积分时间 + 100ms

### Q2: 持续测量时出现超时错误
**原因**：数据传输时间超过定时器间隔

**解决方案**：
- 增加定时器间隔
- 修改代码：`int intervalMs = m_spectrometer->getIntegrationTime() / 1000 + 200;`

### Q3: 单次测量成功，但持续测量失败
**原因**：定时器未正确初始化或连接

**检查**：
1. 确认 `m_measureTimer` 已初始化
2. 确认定时器信号已连接到槽函数
3. 查看调试输出

### Q4: 如何调整采集频率？
**方法 1**：修改积分时间
```cpp
m_spectrometer->setIntegrationTime(5000);  // 5ms
// 采集频率 ≈ 1000 / (5 + 100) ≈ 9.5 Hz
```

**方法 2**：修改定时器间隔
```cpp
// 在 on_btnContinuousMeasure_clicked() 中
int intervalMs = 200;  // 固定 200ms 间隔
m_measureTimer->start(intervalMs);
```

## 性能指标

### 采集速度
- **单次测量**：积分时间 + 数据传输时间（约 50-100ms）
- **持续测量**：
  - 积分时间 10ms：约 9 Hz
  - 积分时间 50ms：约 6.7 Hz
  - 积分时间 100ms：约 5 Hz

### 数据量
- **像素数**：通常 2048 或 3648
- **每帧数据**：像素数 × 2 字节
- **传输速率**：115200 bps
- **传输时间**：约 (像素数 × 2 × 10) / 115200 秒

### 内存占用
- **单帧数据**：约 4-8 KB
- **图表缓存**：约 100-200 KB
- **总内存**：< 10 MB
