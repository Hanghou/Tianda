1）起始码：1 字节，通信起始码；
字节： 68H
2）设备 ID：4 字节，表示设备的软硬件版本和出厂编号，此设备无；
字节： OO OO OO OO
3）控制字：1 字节，用于区分控制命令；
字节： 根据实际数据而定
4）数据长度：2 字节，高字节在前，低字节在后。若为零表示无数据域；
字节：根据实际数据域长度而定
5）数据域：长度不大于 300 字节；
字节：根据实际数据而定
6）校验码：采用累加和取反的校验方式，发送方将设备 ID、控制字、数据
长度和数据区的所有字节进行算术累加，抛弃高位，只保留最后单字节，
将单字节取反；
字节：根据实际数据而定
7）结束符：1 字节，通信结束码；
字节： 16H

2.3 校验
采用累加和取反的校验方式，发送方将设备 ID、控制字、数据长度和数
据区的所有字节进行算术累加，抛弃高位，只保留最后单字节，将单字节取
反
称：Checksum
明：累加和取反校验函数
参：*p 效验帧的指针 帧长 datalen
//**********************************************************************
//**名
//**说
//**形
//**返 回 值：校验字
//**********************************************************************
u8 Checksum (u8 * p, u16 datalen )
{
unsigned char Cksum = 0;
int i;
for(i=0;i<datalen;i++)
{
Cksum += *(p+i);
}
return (~Cksum);
}
