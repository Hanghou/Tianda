# 激光器驱动测试指南

## 协议验证（已确认与官方文档一致）

根据 OHLD-1000 协议文档截图，以下是各个命令的预期输出：

### 1. 查询状态命令
```
发送: 68 00 00 00 00 01 00 04 00 00 00 00 FA 16
接收: 68 00 00 00 00 01 00 12 [18字节状态数据] [校验码] 16
```
**校验码计算：**
- 数据：00 00 00 00 01 00 04 00 00 00 00
- 累加和：05H
- 取反：FAH ✓

### 2. 开启激光器命令
```
发送: 68 00 00 00 00 05 00 04 00 00 00 00 F6 16
接收: 68 00 00 00 00 05 00 00 FA 16
```
**校验码计算：**
- 数据：00 00 00 00 05 00 04 00 00 00 00
- 累加和：09H
- 取反：F6H ✓

### 3. 关闭激光器命令
```
发送: 68 00 00 00 00 06 00 04 00 00 00 00 F5 16
接收: 68 00 00 00 00 06 00 00 F9 16
```
**校验码计算：**
- 数据：00 00 00 00 06 00 04 00 00 00 00
- 累加和：0AH
- 取反：F5H ✓

### 4. 设置电流命令（例：300mA）
```
发送: 68 00 00 00 00 02 00 04 0B B8 00 00 36 16
      - 0BB8H = 3000 (300mA * 10)
      - 数据域只用到前2字节，后2字节填充00
接收: 68 00 00 00 00 02 00 00 FD 16
```
**校验码计算：**
- 数据：00 00 00 00 02 00 04 0B B8 00 00
- 累加和：C9H
- 取反：36H ✓

### 5. 设置最大电流命令（例：300mA）
```
发送: 68 00 00 00 00 03 00 04 01 2C 00 00 CB 16
      - 012CH = 300 (直接使用实际值，不*10)
      - 数据域只用到前2字节，后2字节填充00
接收: 68 00 00 00 00 03 00 00 FC 16
```
**校验码计算：**
- 数据：00 00 00 00 03 00 04 01 2C 00 00
- 累加和：34H
- 取反：CBH ✓

### 6. 设置温度命令（例：25.0℃）
```
发送: 68 00 00 00 00 04 00 04 41 C8 00 00 EE 16
      - 41 C8 00 00 = 25.0 (IEEE 754 浮点数)
接收: 68 00 00 00 00 04 00 00 FB 16
```
**校验码计算：**
- 数据：00 00 00 00 04 00 04 41 C8 00 00
- 累加和：11H
- 取反：EEH ✓

### 7. 设置温度命令（例：22.1℃）
```
发送: 68 00 00 00 00 04 00 04 41 B0 CC CD 6D 16
      - 41 B0 CC CD = 22.1 (IEEE 754 浮点数)
接收: 68 00 00 00 00 04 00 00 FB 16
```
**校验码计算：**
- 数据：00 00 00 00 04 00 04 41 B0 CC CD
- 累加和：92H
- 取反：6DH ✓

## 校验码计算验证（已确认正确）

校验码算法：**累加和取反**

公式：`校验码 = ~(所有字节累加和)`

### 示例1：查询命令
```
数据: 00 00 00 00 01 00 04 00 00 00 00
累加和: 00+00+00+00+01+00+04+00+00+00+00 = 05H
取反: ~05H = FAH ✓
```

### 示例2：设置300mA电流
```
数据: 00 00 00 00 02 00 04 0B B8 00 00
累加和: 00+00+00+00+02+00+04+0B+B8+00+00 = C9H
取反: ~C9H = 36H ✓
```

### 示例3：设置22.1℃温度
```
数据: 00 00 00 00 04 00 04 41 B0 CC CD
累加和: 00+00+00+00+04+00+04+41+B0+CC+CD = 92H (忽略进位)
取反: ~92H = 6DH ✓
```

**注意：** 累加时如果超过 0xFF，只保留低 8 位（自动溢出）

## 三个激光器的区别

1. **种子源激光器** (SeedSource)
   - 电流单位：mA
   - 例如：300mA → 发送 3000 (0BB8H)

2. **FOPO激光器** (FOPO)
   - 电流单位：A
   - 例如：3A → 发送 30 (001EH)

3. **Stokes激光器** (Stokes)
   - 电流单位：mA
   - 例如：300mA → 发送 3000 (0BB8H)

## 注意事项

1. 所有命令的数据域都是 4 字节（固定长度）
2. 设置电流时，实际值需要 *10
3. 设置最大电流时，直接使用实际值，不需要 *10
4. 温度使用 IEEE 754 浮点数格式
5. 校验码是从设备ID到数据域的累加和取反
6. 串口设置：9600, 8N1, 无流控
