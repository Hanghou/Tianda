# 激光器驱动模块

## 功能概述
控制三个独立的激光器：
- **种子源激光器**（Seed Source）- 单位：mA
- **FOPO激光器** - 单位：A（内部转换为mA）
- **Stokes激光器** - 单位：mA

## 通信协议
**激光器和放大器通信协议**（Connet Fiber Optics Co., Ltd.）
- 串口通信：9600 bps, 8N1
- 帧格式：`0xAA 0x55 + 命令字 + 数据长度 + 数据 + 校验和(2字节)`
- 校验算法：所有字节相加，取低16位（低字节在前，高字节在后）

## 主要功能
- ✅ 读取基本信息（0xD1命令）- 获取功率设置方式
- ✅ 设置泵浦电流/功率（0xC3命令）- 根据功率设置方式决定
- ✅ 开启/关闭激光器（0xC1命令）- 1字节数据（1=开，0=关）
- ❌ 设置最大电流（新协议不支持）
- ❌ 设置温度（新协议不支持，但有0xC7命令设置种子激光器温度）
- ❌ 查询状态（新协议不支持独立的查询状态命令，使用0xD3读取实时信息）

## 功率设置方式
根据基本信息报文第25字节，设备支持以下功率设置方式（1个产品只有1种）：
1. 设置功率
2. 设置电流
3. 设置DA
4. 电位器
5. 固定功率
6. 通过电压设置
7. 设置泵浦功率
8. 设置峰值功率
9. 设置增益
10. 设置监测功率

## 使用示例

### 连接激光器（自动开启）
```cpp
LaserDriver *seedLaser = new LaserDriver(LaserType::SeedSource);
seedLaser->openPort("COM3", 9600);

// 连接成功后会自动调用turnOn()开启激光器
```

### 断开激光器（自动关闭）
```cpp
// 断开前会自动调用turnOff()关闭激光器
seedLaser->disconnect();
```

### 读取基本信息（可选）
```cpp
// 读取基本信息，确认功率设置方式
seedLaser->readBasicInfo();
// 等待应答后，检查功率设置方式
LaserBasicInfo info = seedLaser->getBasicInfo();
if (info.powerSetMode == 2) {
    qDebug() << "设备支持设置电流模式";
}
```

### 设置泵浦电流
```cpp
// 种子源：500 mA
seedLaser->setPumpCurrent(500);

// 或使用兼容接口
seedLaser->setCurrent(500.0f);

// FOPO：3 A（自动转换为3000 mA）
fopoLaser->setCurrent(3.0f);
```

### 手动开启/关闭（可选）
```cpp
seedLaser->turnOn();   // 手动开启（连接时已自动开启）
seedLaser->turnOff();  // 手动关闭（断开时会自动关闭）
```

## 重要提示
⚠️ **三个激光器完全独立**
- 每个激光器有独立的 `LaserDriver` 实例
- 每个激光器连接到不同的串口
- 命令不会混淆或串扰

⚠️ **电流单位不同**
- 种子源和 Stokes：mA（毫安）
- FOPO：A（安培，内部自动转换为mA）

⚠️ **自动开启/关闭**
- 连接成功后会自动调用`turnOn()`开启激光器
- 断开前会自动调用`turnOff()`关闭激光器
- 无需手动控制开启/关闭

⚠️ **功率设置方式**
- 使用前建议先调用`readBasicInfo()`读取设备的功率设置方式
- 根据功率设置方式（第25字节）确定0xC3命令的作用
- 功率设置方式=2时，0xC3命令设置电流
- 功率设置方式=1时，0xC3命令设置功率

⚠️ **开启/关闭使用同一命令**
- 0xC1命令用于开启和关闭光源
- 数据字节：1=开启，0=关闭
- 0xC2命令是"返回出厂设置"，不是关闭命令

## 协议示例

### 设置泵浦电流500mA（功率设置方式=2时）
```
下发：0xAA 0x55 0xC3 0x02 0xF4 0x01 [校验和2字节]
应答：0x55 0xAA 0xC3 0x01 0x00 [校验和2字节]
```

### 开启激光器
```
下发：0xAA 0x55 0xC1 0x01 0x01 [校验和2字节]
应答：0x55 0xAA 0xC1 0x01 0x00 [校验和2字节]
```

### 关闭激光器
```
下发：0xAA 0x55 0xC1 0x01 0x00 [校验和2字节]
应答：0x55 0xAA 0xC1 0x01 0x00 [校验和2字节]
```

### 读取基本信息
```
下发：0xAA 0x55 0xD1 0x00 [校验和2字节]
应答：0x55 0xAA 0xD1 [数据长度] [数据...] [校验和2字节]
      第25字节为功率设置方式
```
